## Cómo crear la siguiente spec

1. Leer la [constitución](../constitution.md), la trazabilidad y las aclaraciones que afectan a la funcionalidad.
2. Elegir el número reservado en esta tabla; para una división posterior autorizada, usar el siguiente libre de tres dígitos sin renumerar documentos existentes.
3. Usar [spec-template.md](spec-template.md), adaptada de `spec-generator`, conservando todas sus secciones.
4. Referenciar las HU originales y numerar criterios EARS locales como `RF-1`, `RF-2`, etc., siempre con su fuente original. Para referencias entre specs usar, por ejemplo, `001/RF-1`.
5. Preguntar una cosa a la vez. No introducir políticas ni mecanismos técnicos para rellenar vacíos.
6. Pedir aprobación explícita de esa spec. Solo después crear su `plan.md` y `tasks.md` en la misma carpeta.
